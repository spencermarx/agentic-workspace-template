# Output template

Loaded on demand by the [`seven-copy-critics`](../SKILL.md) skill when it
compiles its report. Follow the section order exactly: the report is read
top-down by someone deciding whether to ship.

## Output Template

The full skill output should follow this structure exactly:

```markdown
# Seven Critics Review - [draft title or first 6 words]

**Audience:** [target persona]
**Channel:** [format]
**Desired action:** [what we want the reader to do]

## ORIGINAL DRAFT
[paste]

## CRITIC FINDINGS
### 1. Time-Crushed
- First Impression: ...
- Trust & Engagement: ...
- Action: ...
[...repeat for all 7 critics...]

## FAILURE REPORT
[categorized]

## REBUILT COPY
[full rewrite]

## VALIDATION PASS
[7 critics, PASS/FAIL each]

## WHAT CHANGED
[changelog]
```
