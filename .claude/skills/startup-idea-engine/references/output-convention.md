# Output convention and voice

Loaded on demand by the [`startup-idea-engine`](../SKILL.md) skill at stage 5.

## Output Convention

Every session writes:

```
{user-specified-destination}/{YYYY-MM-DD}-startup-idea-engine-session.md
{user-specified-destination}/{candidate-name} — Problem and Solution Space.md  (one per surviving candidate)
```

If the user opted in during Phase 0 and the destination is a retreat folder:

```
Updates appended to: {retreat}/the operator/02 Heretical Theses Pool.md
```

Session document required sections:
- Frontmatter: `date`, `mode`, `scope_hint`, `output_destination`, `theses_pool_updated`
- Phase 0 setup record
- Phase 1 context summary (≤5 bullets, work-anchored)
- Phase 2 noticing output (per-procedure candidates)
- Phase 3 framework test matrix
- Phase 4 research findings
- Phase 5 adversarial review record (which critics ran, what failed, what was refined, any unresolved dissent — never buried)
- Phase 6 ranked candidates + recommendation
- Phase 7 forcing question

Raw Idea documents follow `references/raw-idea-template.md` exactly. The template matches the retreat's existing pattern (Fluid Websites, Mesh Substrate, etc.) so new docs are visually and structurally consistent with the corpus.

---

## Voice & Tone

Garry-shaped (per the gstack /office-hours posture): lead with the point, be concrete (name files, numbers, real outcomes), tie technical / market choices to user outcomes, be direct about quality, never corporate or hedged. No em dashes. No filler ("interesting," "comprehensive," "robust"). The session is adversarial during Phases 3–5 (hard tests, hard critics) and synthesis-mode during Phase 6 (clear recommendation with conviction).

Specificity over generality, always. Named segments, specific evidence, concrete data points. "Ops VP at a $50M+ PE-rolled trades portfolio with 5+ acquired the incumbent vendor shops" beats "operations leaders at multi-shop businesses."
